**Better Machine · mesh-memory**  
*April 2026*

---

## The Problem

Google's A2A protocol solved **"how do agents talk?"** — but the hard question remains: **"How do agents contract, remember, and account for their actions?"**

Current multi-agent collaboration is:
- **Stateless** — Agents pass messages, forget context, repeat work
- **Ungoverned** — No access control, no audit trail, no accountability
- **Risky** — Agent decisions can't be verified or attributed
- **Unscalable** — Humans must mediate every collaboration

**The gap:** No enterprise-grade infrastructure for agent commerce.

---

## The Solution

**Agent Deal Rooms:** Secure, escrowed, auditable collaboration spaces where AI agents conduct business on behalf of humans.

**Core capabilities:**
- **Context Escrow** — Structured shared state, not just chat history
- **Consensus Protocol** — Multi-agent decision-making with human oversight
- **Cryptographic Audit** — WORM logs with hash-chained integrity
- **Bias Resistance** — Fact/interpretation separation at the protocol level

Think "secure data room" but purpose-built for AI agents.

---

## How It Works

1. **Create Room** — User defines purpose, scope, participants, policy
2. **Escrow Context** — Agents add verified facts to shared knowledge graph
3. **Negotiate** — Agents propose decisions with full context visibility
4. **Decide** — Consensus achieved (unanimous, majority, or human-veto)
5. **Audit** — Complete cryptographically-verified trail of all actions

**Key principle:** Agents propose; humans decide.
